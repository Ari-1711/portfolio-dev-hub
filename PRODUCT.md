# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack
React.js (via Vite) + Tailwind CSS + React Router (Frontend), Node.js + Express.js REST API (Backend), Vercel (Deployment)

## Users
Technical recruiters, hiring managers, engineering leads, and selection committees for tech scholarships/bootcamps evaluating candidates for full-stack, software engineering, or AI/ML roles.

## Product Purpose
A centralized developer portfolio and interactive hub created to demonstrate full-stack proficiency, showcase production-grade AI/ML projects, and exhibit senior software engineering standards.

## Positioning
A production-grade, full-stack portfolio backed by a live REST API backend and clean architecture—setting itself apart from static templates by delivering interactive project demos (such as the Smart Waste Management System) and verifiable code craft.

## Operating Context
Fast preliminary scanning by recruiters on mobile and desktop devices, detailed technical evaluation by engineering leads inspecting live API endpoints and GitHub source code, and immediate direct contact via multi-channel communication options.

## Capabilities and Constraints
- **Interactive Project Showcase:** Cards highlighting real-world applications (e.g., Smart Waste Management System) with tech tags, problem statements, live demo links, and GitHub repos.
- **Live REST API Integration:** Node.js/Express backend serving dynamic portfolio data and processing contact inquiries.
- **Interactive Contact Form:** Connected to API endpoints with explicit `loading`, `success`, and `error` UI states.
- **Tech Stack & Skills Matrix:** Visual grid covering Frontend (React.js, Tailwind CSS), Backend (Node.js, Express, REST APIs), Tools (Git, GitHub, Vercel), and AI/ML (Python, MobileNetV2).
- **Interactive Resume & Education Timeline:** Structured timeline highlighting academic background (Informatics Engineering at Mercu Buana University), certifications, and tech programs.
- **Dark-Mode Native Responsive Design:** Mobile-first, accessible UI built with Tailwind CSS.
- **Comprehensive Social & Direct Connect Hub:** One-click connect bar (GitHub, LinkedIn, WhatsApp Direct `wa.me`, Email `mailto`, Instagram).

## Brand Commitments
- **Developer Identity:** Ari (Informatics Engineering Student & Full-Stack / AI Developer).
- **Voice:** Professional, technically precise, clear, and confident.
- **Visual Identity:** Dark-mode native, sleek modern tech aesthetic, polished contrast, clean spacing.

## Evidence on Hand
- **Featured Project:** Smart Waste Management System (MobileNetV2, Python, Web integration).
- **Academic Context:** Informatics Engineering student at Mercu Buana University.
- **Repository:** https://github.com/Ari-1711/portfolio-dev-hub

## Product Principles
- **Proof over Claims:** Demonstrate technical competence through live REST API endpoints, runnable demos, and public GitHub source code.
- **Scannable Precision:** Structure information so recruiters understand key strengths within seconds, while providing depth for engineering leads.
- **Explicit Operational States:** Always handle and render API states (`loading`, `error`, `success`) explicitly in the UI.
- **Mobile-First & Accessible:** Deliver responsive design, crisp contrast, and fast performance across all viewports.
